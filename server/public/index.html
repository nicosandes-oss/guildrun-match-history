Drag your log file here, or click to choose it
Where to find your log file:
In your GuildRun install folder, under Guildrun_Data\Logs — pick the log from the session you just played.

What gets stored on this site:
Your Steam display name, run outcomes, heroes used, relics collected, and run duration. Nothing else. No email, no IP address tracking, no analytics.

GuildRun History is an independent fan-made run tracker, not affiliated with or endorsed by Leyline Games.

The companion app only reads GuildRun log files and sends run summaries (heroes, relics, outcome, duration) to this site. It does not modify game files, access other programs, or collect personal information.
