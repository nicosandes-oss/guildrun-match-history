Track your runs automatically
A small Windows app that watches your GuildRun logs and uploads your runs to this site automatically — no setup, no config files, no technical knowledge needed.
Download Companion (.exe)
How it works:
1. Download and run GuildRunCompanion.exe
2. First launch: enter your Steam display name once
3. Leave it open while you play — runs upload automatically
4. Close it when you're done playing

What the app does:
• Reads your GuildRun log files (same folder the game creates them in)
• Sends your run summary to this site: heroes, relics, outcome, duration
• Never reads anything outside the GuildRun log folder
• Never modifies any game files
• No account, no login, no password required

What gets stored on this site:
Your Steam display name, run outcomes, heroes used, relics collected, and run duration. Nothing else. No email, no IP address tracking, no analytics.

GuildRun History is an independent fan-made run tracker, not affiliated with or endorsed by Leyline Games.

The companion app only reads GuildRun log files and sends run summaries (heroes, relics, outcome, duration) to this site. It does not modify game files, access other programs, or collect personal information.
